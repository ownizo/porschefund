# Porsche Fund

Humorous crowdfunding page for a regular Portuguese guy trying to buy a Porsche Taycan by his 42nd birthday (August 2, 2027).

## Files
- `index.html` — main homepage
- `admin.html` — simple admin to update the counter (localStorage)

## Notes
- Counter defaults to 0 and can be updated via admin.html (per browser) or by editing the JS in index.html and committing.
- Bank details are public as requested.
- If goal not reached by the deadline, funds go to a charity of the organizer’s choice.

Deploy as GitHub Pages from the main branch.
